# Quick Start Guide - YouTube Loop Player

## 🚀 Getting Started (3 Easy Steps)

### 1. Open the Tool
Double-click `youtube-loop-player.html` to open it in your web browser.

### 2. Enter a Video URL
Paste any of these formats:
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`
- `dQw4w9WgXcQ` (just the video ID)

### 3. Click "Start Loop Player"
The video will start playing and automatically loop with variations!

## 🎯 What Happens Next?

Each time the video loops:
- **Speed changes** randomly (0.5x to 2x)
- **Start position** changes randomly (first 30% of video)
- **Loop counter** increments
- **Stats update** in real-time

## 📱 Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- JavaScript enabled

## ❓ Common Issues

### Button says "Loading API..."
Wait a few seconds for YouTube API to load. Button will change to "Start Loop Player" when ready.

### Error: "Video owner does not allow embedding"
Some videos restrict embedding. Try a different video.

### Error: "Video not found"
Check that the URL or video ID is correct and the video exists.

## 💡 Tips

- Works great for music, learning videos, tutorials
- Each loop feels unique due to random variations
- Use with educational content for better retention
- Perfect for practicing along with tutorial videos
